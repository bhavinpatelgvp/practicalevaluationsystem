# User Manual

## Administrator

Seed or create roles, departments, subjects, faculty, and student records. Review dashboard statistics and audit events. Production administration should use controlled migrations and institutional identity management.

## Faculty

Open **Practicals**, create a practical with a grade and submission date, then assign it to all enrolled students. Review submissions in **Evaluate**, open the repository, enter criterion marks, and publish remarks and suggestions. Published evaluations appear in the student workspace.

## Student

Open **Practicals**, review the deadline, and submit a public GitHub repository URL with optional commit, branch, and documentation details. Before the deadline, the same submission can be updated. After publication, marks and remarks appear under the practical.
